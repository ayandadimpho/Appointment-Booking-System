# Appointment Booking System

## Overview
The Appointment Booking System is a Python based application designed to manage appointments bookings between users and service providers.

## Objectives
- Allow users to book available slots.
- Prevent double booking.
- Allow users to cancel bookings.
- Validate appointment information.

## Features
- Create appointments
- View available appointment slots
- Book appointments
- Cancel appointments
- Prevent conflicting bookings
- Validate date and times

## Testing approach
This project follows Test-Driven Development (TDD) using the Red-Green-Refactor cycle.

## Red
Write a test that fails.

## Green
Write the minimum code required to make the test pass.

## Refactor
Improve the code while keeping the tests passing.
